# Sundry v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native macOS app that generates a grounded, destination- and season-aware packing checklist on-device and lets you check items off.

**Architecture:** A Rust core (`sundry-core`) owns the domain model, an Automerge document per trip, and the generation pipeline. It performs no network I/O: both the LLM inference call and the climate lookup are async UniFFI callback interfaces implemented in Swift. A thin `sundry-ffi` crate exposes the core as an xcframework, consumed by a SwiftUI app that draws views and provides those two transports.

**Tech Stack:** Rust (automerge, serde, serde_json, uuid, chrono, uniffi), Swift 6 / SwiftUI, Apple Foundation Models framework, Open-Meteo HTTP API, Xcode 26.

## Global Constraints

- Must be free to run. No paid APIs, no subscriptions, no per-token cost. No API keys anywhere in the codebase.
- macOS 26.0 (Tahoe) minimum, Apple Silicon only, Apple Intelligence must be enabled.
- Facts are never generated by the model. Sockets, voltage, currency, and climate are always looked up and injected into the prompt.
- Sundry never asserts a visa or entry requirement as fact.
- The category taxonomy is fixed at exactly 11 values and is never model-generated.
- Regeneration is additive and must never mutate existing item state.
- Rust core has no HTTP dependency and no async runtime dependency.
- The app is sandboxed with the outgoing-network entitlement from the first commit.
- Spec: [docs/superpowers/specs/2026-08-13-sundry-design.md](../specs/2026-08-13-sundry-design.md)

## Phase 1 — Prove the assumption

### Task 1: Quality spike (throwaway)

The entire design rests on an unproven claim: that a heavily grounded 3B on-device model produces genuinely useful packing lists. Apple explicitly warns against relying on this model for world knowledge. Prove or disprove this before writing any real code. **If this task fails, stop and revisit the spec — do not proceed to Task 2.**

**Files:**
- Create: `spike/spike.swift`

- [ ] **Step 1: Create a standalone Swift script with a hand-written grounded prompt**

```swift
// spike/spike.swift
// Run: swift spike/spike.swift
import FoundationModels

@Generable
struct SpikeItem {
    @Guide(description: "Short item name, e.g. 'Type F plug adapter'")
    let name: String
    @Guide(description: "How many to pack")
    let quantity: Int
    @Guide(description: "One sentence explaining why this trip needs it")
    let rationale: String
}

@Generable
struct SpikeList {
    let items: [SpikeItem]
}

let grounded = """
Trip facts (authoritative — do not contradict these):
- Destination: Kyoto, Japan
- Travel month: November
- Nights: 7
- Travellers: 2 adults
- Purpose: city sightseeing, some temple walking
- Mains electricity: 100V, 50Hz, socket types A and B
- Currency: JPY
- Drives on: left
- Tap water: potable
- Climate normals for November: average high 17C, average low 7C, \
precipitation 60mm over the month, about 10 hours of daylight

Task: list the ELECTRONICS a traveller should pack for this trip.
Only electronics. Use the facts above rather than your own knowledge.
Explain each item in one sentence.
"""

let model = SystemLanguageModel.default
guard case .available = model.availability else {
    print("UNAVAILABLE: \(model.availability)")
    exit(1)
}

let session = LanguageModelSession()
let result = try await session.respond(to: grounded, generating: SpikeList.self)
for item in result.content.items {
    print("- \(item.name) x\(item.quantity): \(item.rationale)")
}
```

- [ ] **Step 2: Run it and read the output critically**

Run: `swift spike/spike.swift`

Expected: a list of electronics that references the supplied facts. The bar to pass is specific and worth being strict about:
- It must recommend a plug adapter appropriate to type A/B sockets, or correctly note that a traveller from a type A/B country needs none.
- It must not contradict any supplied fact (e.g. must not claim Japan is 230V).
- Rationales must reference trip specifics, not be generic filler like "useful for travel".
- It must stay inside the electronics category rather than drifting into clothing.

- [ ] **Step 3: Repeat with a second, contrasting destination**

Change the grounded block to Reykjavik, Iceland in February: 230V, 50Hz, socket types C and F, ISK, drives on right, potable water, average high 3C, average low -2C, 78mm precipitation, 9 hours daylight. Change the task line to `list the CLOTHING a traveller should pack`.

Run: `swift spike/spike.swift`

Expected: cold and wet weather clothing that reflects −2 °C and the short daylight. Confirms the model responds to the grounded facts rather than producing a generic list regardless of input. If both destinations produce near-identical output, grounding is not reaching the model and the design does not work as specified.

```rust
// sundry-core/src/model.rs  (above the tests module)
use chrono::NaiveDate;
use serde::{Deserialize, Serialize};
use uuid::Uuid;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum Category {
    Documents,
    Money,
    Electronics,
    Clothing,
    Footwear,
    Toiletries,
    Health,
    Bags,
    Comfort,
    Activity,
    Misc,
}

impl Category {
    pub const ALL: [Category; 11] = [
        Category::Documents,
        Category::Money,
        Category::Electronics,
        Category::Clothing,
        Category::Footwear,
        Category::Toiletries,
        Category::Health,
        Category::Bags,
        Category::Comfort,
        Category::Activity,
        Category::Misc,
    ];

    pub fn label(&self) -> &'static str {
        match self {
            Category::Documents => "Documents",
            Category::Money => "Money",
            Category::Electronics => "Electronics",
            Category::Clothing => "Clothing",
            Category::Footwear => "Footwear",
            Category::Toiletries => "Toiletries",
            Category::Health => "Health & Medication",
            Category::Bags => "Bags & Organisation",
            Category::Comfort => "Comfort & Entertainment",
            Category::Activity => "Activity-Specific",
            Category::Misc => "Miscellaneous",
        }
    }

    pub fn from_label(label: &str) -> Option<Category> {
        Category::ALL.into_iter().find(|c| c.label() == label)
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum ItemState {
    Todo,
    Packed,
    NotNeeded,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum ItemSource {
    Model,
    Manual,
    Learned,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub enum Owner {
    Shared,
    Traveller(Uuid),
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Item {
    pub id: Uuid,
    pub name: String,
    pub quantity: u32,
    pub category: Category,
    pub owner: Owner,
    pub state: ItemState,
    pub source: ItemSource,
    pub rationale: Option<String>,
    pub note: Option<String>,
    pub essential: bool,
}

impl Item {
    pub fn manual(name: &str, category: Category) -> Self {
        Item {
            id: Uuid::new_v4(),
            name: name.to_string(),
            quantity: 1,
            category,
            owner: Owner::Shared,
            state: ItemState::Todo,
            source: ItemSource::Manual,
            rationale: None,
            note: None,
            essential: false,
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum Purpose {
    Business,
    Leisure,
    Hiking,
    Beach,
    City,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Traveller {
    pub id: Uuid,
    pub name: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub enum TravelWindow {
    Month { year: i32, month: u32 },
    Dates { start: NaiveDate, end: NaiveDate },
}

impl TravelWindow {
    pub fn month(&self) -> u32 {
        match self {
            TravelWindow::Month { month, .. } => *month,
            TravelWindow::Dates { start, .. } => chrono::Datelike::month(start),
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Destination {
    pub country_code: String,
    pub city: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Trip {
    pub id: Uuid,
    pub title: String,
    pub destinations: Vec<Destination>,
    pub window: TravelWindow,
    pub nights: u32,
    pub travellers: Vec<Traveller>,
    pub purposes: Vec<Purpose>,
}
```

```rust
// sundry-core/src/facts.rs  (above the tests module)
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum DrivingSide {
    Left,
    Right,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum TapWater {
    Potable,
    NotPotable,
    Caution,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct CountryFacts {
    pub code: String,
    pub name: String,
    pub plug_types: Vec<String>,
    pub voltage: u32,
    pub frequency: u32,
    pub currency: String,
    pub drives_on: DrivingSide,
    pub tap_water: TapWater,
}

const RAW: &str = include_str!("../data/country-facts.json");

pub struct FactsTable {
    by_code: HashMap<String, CountryFacts>,
}

impl FactsTable {
    pub fn load() -> Self {
        let rows: Vec<CountryFacts> =
            serde_json::from_str(RAW).expect("bundled country-facts.json is malformed");
        let by_code = rows
            .into_iter()
            .map(|f| (f.code.to_uppercase(), f))
            .collect();
        FactsTable { by_code }
    }

    pub fn get(&self, code: &str) -> Option<&CountryFacts> {
        self.by_code.get(&code.to_uppercase())
    }

    pub fn all(&self) -> impl Iterator<Item = &CountryFacts> {
        self.by_code.values()
    }

    pub fn len(&self) -> usize {
        self.by_code.len()
    }

    pub fn is_empty(&self) -> bool {
        self.by_code.is_empty()
    }
}
```

`load()` panics on malformed data deliberately: the file is compiled into the binary, so a parse failure is a build-time authoring bug that must never ship, not a runtime condition to handle.

```rust
// sundry-core/src/climate.rs  (above the tests module)
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct ClimateNormals {
    pub avg_high_c: f64,
    pub avg_low_c: f64,
    pub precipitation_mm: f64,
    pub daylight_hours: f64,
}

#[derive(Debug, thiserror::Error, PartialEq, Eq)]
pub enum ClimateError {
    #[error("climate service unreachable")]
    Unreachable,
    #[error("no climate data for this location")]
    NotFound,
}

#[async_trait::async_trait]
pub trait ClimateProvider: Send + Sync {
    async fn normals(
        &self,
        city: String,
        country_code: String,
        month: u32,
    ) -> Result<ClimateNormals, ClimateError>;
}

#[cfg(any(test, feature = "test-support"))]
pub struct FakeClimateProvider {
    outcome: Result<ClimateNormals, ClimateError>,
}

#[cfg(any(test, feature = "test-support"))]
impl FakeClimateProvider {
    pub fn returning(normals: ClimateNormals) -> Self {
        FakeClimateProvider { outcome: Ok(normals) }
    }

    pub fn failing() -> Self {
        FakeClimateProvider { outcome: Err(ClimateError::Unreachable) }
    }
}

#[cfg(any(test, feature = "test-support"))]
#[async_trait::async_trait]
impl ClimateProvider for FakeClimateProvider {
    async fn normals(
        &self,
        _city: String,
        _country_code: String,
        _month: u32,
    ) -> Result<ClimateNormals, ClimateError> {
        self.outcome.clone()
    }
}
```

Add to `sundry-core/Cargo.toml`:

```toml

[features]
test-support = []
```

```rust
// sundry-core/src/llm.rs  (above the tests module)
use serde::{Deserialize, Serialize};
use std::collections::HashSet;
use std::sync::Mutex;

pub const MAX_QUANTITY: u32 = 20;

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct GeneratedItem {
    pub name: String,
    pub quantity: u32,
    pub rationale: String,
    pub essential: bool,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct GeneratedList {
    pub items: Vec<GeneratedItem>,
}

#[derive(Debug, thiserror::Error, Clone, PartialEq, Eq)]
pub enum LlmError {
    #[error("the on-device model is unavailable")]
    Unavailable,
    #[error("inference failed: {0}")]
    Failed(String),
}

#[derive(Debug, thiserror::Error)]
pub enum ValidationError {
    #[error("response was not parseable JSON: {0}")]
    Unparseable(String),
    #[error("response contained no usable items")]
    NoUsableItems,
}

/// Canonical form used for duplicate detection, here and in `document.rs`.
pub fn normalise(name: &str) -> String {
    name.split_whitespace()
        .collect::<Vec<_>>()
        .join(" ")
        .to_lowercase()
}

pub fn parse_and_validate(raw: &str) -> Result<Vec<GeneratedItem>, ValidationError> {
    let parsed: GeneratedList =
        serde_json::from_str(raw).map_err(|e| ValidationError::Unparseable(e.to_string()))?;

    let mut seen: HashSet<String> = HashSet::new();
    let mut kept = Vec::new();

    for item in parsed.items {
        let name = item.name.trim().to_string();
        if name.is_empty() {
            continue;
        }
        if item.quantity == 0 || item.quantity > MAX_QUANTITY {
            continue;
        }
        if !seen.insert(normalise(&name)) {
            continue;
        }
        kept.push(GeneratedItem { name, ..item });
    }

    if kept.is_empty() {
        return Err(ValidationError::NoUsableItems);
    }
    Ok(kept)
}

#[async_trait::async_trait]
pub trait LlmBackend: Send + Sync {
    async fn generate(&self, prompt: String) -> Result<String, LlmError>;
}

#[cfg(any(test, feature = "test-support"))]
pub struct FakeLlmBackend {
    responses: Mutex<Vec<String>>,
    fail_with: Option<LlmError>,
}

#[cfg(any(test, feature = "test-support"))]
impl FakeLlmBackend {
    /// Responses are returned in order; the last one repeats once exhausted.
    pub fn replaying(responses: Vec<String>) -> Self {
        FakeLlmBackend { responses: Mutex::new(responses), fail_with: None }
    }

    pub fn failing(error: LlmError) -> Self {
        FakeLlmBackend { responses: Mutex::new(vec![]), fail_with: Some(error) }
    }
}

#[cfg(any(test, feature = "test-support"))]
#[async_trait::async_trait]
impl LlmBackend for FakeLlmBackend {
    async fn generate(&self, _prompt: String) -> Result<String, LlmError> {
        if let Some(err) = &self.fail_with {
            return Err(err.clone());
        }
        let mut queue = self.responses.lock().unwrap();
        if queue.len() > 1 {
            Ok(queue.remove(0))
        } else {
            queue.first().cloned().ok_or(LlmError::Failed("no scripted response".into()))
        }
    }
}
```

```rust
// sundry-core/src/prompt.rs  (above the tests module)
use crate::climate::ClimateNormals;
use crate::facts::{CountryFacts, DrivingSide, TapWater};
use crate::model::{Category, Purpose, Trip};

pub struct GroundedContext {
    pub trip: Trip,
    pub facts: Vec<CountryFacts>,
    pub climate: Option<ClimateNormals>,
}

fn month_name(month: u32) -> &'static str {
    const NAMES: [&str; 12] = [
        "January", "February", "March", "April", "May", "June", "July",
        "August", "September", "October", "November", "December",
    ];
    NAMES[(month.clamp(1, 12) - 1) as usize]
}

fn purpose_label(p: &Purpose) -> &'static str {
    match p {
        Purpose::Business => "business",
        Purpose::Leisure => "leisure",
        Purpose::Hiking => "hiking and outdoors",
        Purpose::Beach => "beach",
        Purpose::City => "city sightseeing",
    }
}

pub fn build_prompt(ctx: &GroundedContext, category: Category) -> String {
    let mut out = String::new();

    out.push_str("Trip facts (authoritative — do not contradict these):\n");

    for dest in &ctx.trip.destinations {
        out.push_str(&format!("- Destination: {}, {}\n", dest.city, dest.country_code));
    }
    out.push_str(&format!("- Travel month: {}\n", month_name(ctx.trip.window.month())));
    out.push_str(&format!("- Nights: {}\n", ctx.trip.nights));
    out.push_str(&format!("- Travellers: {}\n", ctx.trip.travellers.len()));

    if !ctx.trip.purposes.is_empty() {
        let purposes: Vec<&str> = ctx.trip.purposes.iter().map(purpose_label).collect();
        out.push_str(&format!("- Purpose: {}\n", purposes.join(", ")));
    }

    for facts in &ctx.facts {
        out.push_str(&format!(
            "- {} mains electricity: {}V, {}Hz, socket types {}\n",
            facts.name,
            facts.voltage,
            facts.frequency,
            facts.plug_types.join(", ")
        ));
        out.push_str(&format!("- {} currency: {}\n", facts.name, facts.currency));
        out.push_str(&format!(
            "- {} drives on the {}\n",
            facts.name,
            match facts.drives_on {
                DrivingSide::Left => "left",
                DrivingSide::Right => "right",
            }
        ));
        out.push_str(&format!(
            "- {} tap water: {}\n",
            facts.name,
            match facts.tap_water {
                TapWater::Potable => "safe to drink",
                TapWater::NotPotable => "not safe to drink",
                TapWater::Caution => "varies by region, treat with caution",
            }
        ));
    }

    match &ctx.climate {
        Some(c) => out.push_str(&format!(
            "- Climate normals for {}: average high {:.0}C, average low {:.0}C, \
             {:.0}mm precipitation over the month, about {:.0} hours of daylight\n",
            month_name(ctx.trip.window.month()),
            c.avg_high_c,
            c.avg_low_c,
            c.precipitation_mm,
            c.daylight_hours
        )),
        None => out.push_str(
            "- Climate data is unavailable for this destination. Do not guess the \
             weather; suggest only items that hold regardless of conditions.\n",
        ),
    }

    out.push_str(&format!(
        "\nTask: list the items in the category \"{}\" that these travellers should pack \
         for this trip. Only this category. Use the facts above rather than your own \
         knowledge. Give each item a one-sentence reason referring to something specific \
         about this trip. Mark an item essential only if the trip fails without it.\n",
        category.label()
    ));

    if category == Category::Documents {
        out.push_str(
            "Do not state visa or entry requirements, and do not say whether a visa is \
             needed. List document types to carry only.\n",
        );
    }

    out
}
```

```rust
// sundry-core/src/document.rs  (above the tests module)
use crate::llm::{normalise, GeneratedItem};
use crate::model::{Category, Item, ItemSource, ItemState, Owner, Trip};
use automerge::transaction::Transactable;
use automerge::{AutoCommit, ObjType, ReadDoc, ROOT};
use uuid::Uuid;

const TRIP_KEY: &str = "trip";
const ITEMS_KEY: &str = "items";

#[derive(Debug, thiserror::Error)]
pub enum DocError {
    #[error("automerge error: {0}")]
    Automerge(String),
    #[error("document is malformed: {0}")]
    Malformed(String),
    #[error("no item with id {0}")]
    NoSuchItem(Uuid),
}

impl From<automerge::AutomergeError> for DocError {
    fn from(e: automerge::AutomergeError) -> Self {
        DocError::Automerge(e.to_string())
    }
}

#[derive(Debug, Default, PartialEq, Eq)]
pub struct MergeReport {
    pub added: usize,
    pub skipped_existing: usize,
}

pub struct TripDocument {
    doc: AutoCommit,
}

impl TripDocument {
    pub fn new(trip: &Trip) -> Self {
        let mut doc = AutoCommit::new();
        let json = serde_json::to_string(trip).expect("Trip serialises");
        doc.put(ROOT, TRIP_KEY, json).expect("put trip");
        doc.put_object(ROOT, ITEMS_KEY, ObjType::Map).expect("put items map");
        TripDocument { doc }
    }

    pub fn load(bytes: &[u8]) -> Result<Self, DocError> {
        let doc = AutoCommit::load(bytes)?;
        Ok(TripDocument { doc })
    }

    pub fn save(&mut self) -> Vec<u8> {
        self.doc.save()
    }

    pub fn merge(&mut self, other: &mut TripDocument) -> Result<(), DocError> {
        self.doc.merge(&mut other.doc)?;
        Ok(())
    }

    pub fn trip(&self) -> Result<Trip, DocError> {
        let raw = self.string_at(ROOT, TRIP_KEY)?;
        serde_json::from_str(&raw).map_err(|e| DocError::Malformed(e.to_string()))
    }

    pub fn items(&self) -> Result<Vec<Item>, DocError> {
        let (_, items_obj) = self
            .doc
            .get(ROOT, ITEMS_KEY)?
            .ok_or_else(|| DocError::Malformed("missing items map".into()))?;
        let mut out = Vec::new();
        for key in self.doc.keys(&items_obj) {
            let raw = self.string_at(&items_obj, &key)?;
            let item: Item =
                serde_json::from_str(&raw).map_err(|e| DocError::Malformed(e.to_string()))?;
            out.push(item);
        }
        out.sort_by(|a, b| a.name.cmp(&b.name));
        Ok(out)
    }

    pub fn add_item(&mut self, item: &Item) -> Result<(), DocError> {
        let (_, items_obj) = self
            .doc
            .get(ROOT, ITEMS_KEY)?
            .ok_or_else(|| DocError::Malformed("missing items map".into()))?;
        let json = serde_json::to_string(item).map_err(|e| DocError::Malformed(e.to_string()))?;
        self.doc.put(&items_obj, item.id.to_string(), json)?;
        Ok(())
    }

    pub fn set_item_state(&mut self, id: Uuid, state: ItemState) -> Result<(), DocError> {
        let mut item = self
            .items()?
            .into_iter()
            .find(|i| i.id == id)
            .ok_or(DocError::NoSuchItem(id))?;
        item.state = state;
        self.add_item(&item)
    }

    pub fn merge_generated(
        &mut self,
        category: Category,
        generated: &[GeneratedItem],
    ) -> Result<MergeReport, DocError> {
        let existing: Vec<(Category, String)> = self
            .items()?
            .into_iter()
            .map(|i| (i.category, normalise(&i.name)))
            .collect();

        let mut report = MergeReport::default();

        for g in generated {
            let key = (category, normalise(&g.name));
            if existing.contains(&key) {
                report.skipped_existing += 1;
                continue;
            }
            let item = Item {
                id: Uuid::new_v4(),
                name: g.name.clone(),
                quantity: g.quantity,
                category,
                owner: Owner::Shared,
                state: ItemState::Todo,
                source: ItemSource::Model,
                rationale: Some(g.rationale.clone()),
                note: None,
                essential: g.essential,
            };
            self.add_item(&item)?;
            report.added += 1;
        }

        Ok(report)
    }

    fn string_at<O: AsRef<automerge::ObjId>>(&self, obj: O, key: &str) -> Result<String, DocError> {
        match self.doc.get(obj, key)? {
            Some((value, _)) => value
                .into_string()
                .map_err(|_| DocError::Malformed(format!("{key} is not a string"))),
            None => Err(DocError::Malformed(format!("missing key {key}"))),
        }
    }
}
```

Note that `merge_generated` reads existing state once up front and only ever calls `add_item` for genuinely new items. Existing items are never rewritten, which is what makes the state-preservation guarantee structural rather than something maintained by careful field copying.

```rust
// sundry-core/src/generator.rs  (above the tests module)
use crate::climate::ClimateProvider;
use crate::document::{DocError, TripDocument};
use crate::facts::FactsTable;
use crate::llm::{parse_and_validate, LlmBackend};
use crate::model::Category;
use crate::prompt::{build_prompt, GroundedContext};

pub struct CategoryOutcome {
    pub category: Category,
    pub added: usize,
    pub error: Option<String>,
}

pub struct GenerationOutcome {
    pub climate_grounded: bool,
    pub per_category: Vec<CategoryOutcome>,
}

pub struct Generator<'a> {
    facts: &'a FactsTable,
    climate: &'a dyn ClimateProvider,
    llm: &'a dyn LlmBackend,
}

impl<'a> Generator<'a> {
    pub fn new(
        facts: &'a FactsTable,
        climate: &'a dyn ClimateProvider,
        llm: &'a dyn LlmBackend,
    ) -> Self {
        Generator { facts, climate, llm }
    }

    pub async fn generate_all(
        &self,
        doc: &mut TripDocument,
    ) -> Result<GenerationOutcome, DocError> {
        let trip = doc.trip()?;

        let country_facts = trip
            .destinations
            .iter()
            .filter_map(|d| self.facts.get(&d.country_code).cloned())
            .collect();

        let primary = trip.destinations.first();
        let normals = match primary {
            Some(dest) => self
                .climate
                .normals(dest.city.clone(), dest.country_code.clone(), trip.window.month())
                .await
                .ok(),
            None => None,
        };

        let ctx = GroundedContext {
            trip,
            facts: country_facts,
            climate: normals,
        };

        let mut per_category = Vec::with_capacity(Category::ALL.len());

        for category in Category::ALL {
            let prompt = build_prompt(&ctx, category);
            let outcome = match self.llm.generate(prompt).await {
                Err(e) => CategoryOutcome { category, added: 0, error: Some(e.to_string()) },
                Ok(raw) => match parse_and_validate(&raw) {
                    Err(e) => CategoryOutcome { category, added: 0, error: Some(e.to_string()) },
                    Ok(items) => {
                        let report = doc.merge_generated(category, &items)?;
                        CategoryOutcome { category, added: report.added, error: None }
                    }
                },
            };
            per_category.push(outcome);
        }

        Ok(GenerationOutcome {
            climate_grounded: ctx.climate.is_some(),
            per_category,
        })
    }
}
```

Categories are generated sequentially rather than concurrently. The on-device model serialises requests anyway, and sequential execution keeps the progress reporting in Task 12 straightforward.

```rust
// sundry-core/src/store.rs  (above the tests module)
use crate::document::{DocError, TripDocument};
use serde::{Deserialize, Serialize};
use std::path::PathBuf;
use uuid::Uuid;

#[derive(Debug, thiserror::Error)]
pub enum StoreError {
    #[error("io error: {0}")]
    Io(String),
    #[error("no trip with id {0}")]
    NotFound(Uuid),
    #[error("document error: {0}")]
    Document(String),
}

impl From<std::io::Error> for StoreError {
    fn from(e: std::io::Error) -> Self {
        StoreError::Io(e.to_string())
    }
}

impl From<DocError> for StoreError {
    fn from(e: DocError) -> Self {
        StoreError::Document(e.to_string())
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct TripIndexEntry {
    pub id: Uuid,
    pub title: String,
    pub year: i32,
    pub month: u32,
}

pub struct Store {
    root: PathBuf,
}

impl Store {
    pub fn new(root: PathBuf) -> Self {
        Store { root }
    }

    fn trips_dir(&self) -> PathBuf {
        self.root.join("trips")
    }

    fn path_for(&self, id: Uuid) -> PathBuf {
        self.trips_dir().join(format!("{id}.automerge"))
    }

    fn index_path(&self) -> PathBuf {
        self.root.join("index.json")
    }

    pub fn save(&self, doc: &mut TripDocument) -> Result<(), StoreError> {
        std::fs::create_dir_all(self.trips_dir())?;
        let trip = doc.trip()?;
        std::fs::write(self.path_for(trip.id), doc.save())?;

        let mut index = self.read_index()?;
        index.retain(|e| e.id != trip.id);
        let (year, month) = match trip.window {
            crate::model::TravelWindow::Month { year, month } => (year, month),
            crate::model::TravelWindow::Dates { start, .. } => {
                use chrono::Datelike;
                (start.year(), start.month())
            }
        };
        index.push(TripIndexEntry { id: trip.id, title: trip.title, year, month });
        self.write_index(&index)
    }

    pub fn load(&self, id: Uuid) -> Result<TripDocument, StoreError> {
        let path = self.path_for(id);
        if !path.exists() {
            return Err(StoreError::NotFound(id));
        }
        Ok(TripDocument::load(&std::fs::read(path)?)?)
    }

    pub fn list(&self) -> Result<Vec<TripIndexEntry>, StoreError> {
        self.read_index()
    }

    pub fn delete(&self, id: Uuid) -> Result<(), StoreError> {
        let path = self.path_for(id);
        if path.exists() {
            std::fs::remove_file(path)?;
        }
        let mut index = self.read_index()?;
        index.retain(|e| e.id != id);
        self.write_index(&index)
    }

    fn read_index(&self) -> Result<Vec<TripIndexEntry>, StoreError> {
        let path = self.index_path();
        if !path.exists() {
            return Ok(Vec::new());
        }
        let raw = std::fs::read_to_string(path)?;
        serde_json::from_str(&raw).map_err(|e| StoreError::Io(e.to_string()))
    }

    fn write_index(&self, index: &[TripIndexEntry]) -> Result<(), StoreError> {
        std::fs::create_dir_all(&self.root)?;
        let raw =
            serde_json::to_string_pretty(index).map_err(|e| StoreError::Io(e.to_string()))?;
        std::fs::write(self.index_path(), raw)?;
        Ok(())
    }
}
```

```rust
#[uniffi::export(async_runtime = "tokio")]
impl SundryCore {
    #[uniffi::constructor]
    pub fn new(
        storage_root: String,
        climate: Arc<dyn ClimateTransport>,
        llm: Arc<dyn LlmTransport>,
    ) -> Arc<Self> {
        Arc::new(SundryCore {
            store: Store::new(PathBuf::from(storage_root)),
            facts: FactsTable::load(),
            climate,
            llm,
            open: Mutex::new(None),
        })
    }

    pub fn list_trips(&self) -> Result<Vec<TripSummaryDto>, SundryError> {
        Ok(self
            .store
            .list()
            .map_err(core_err)?
            .into_iter()
            .map(Into::into)
            .collect())
    }

    pub fn create_trip(
        &self,
        title: String,
        city: String,
        country_code: String,
        year: i32,
        month: u32,
        nights: u32,
        traveller_names: Vec<String>,
        purposes: Vec<String>,
    ) -> Result<String, SundryError> {
        let trip = Trip {
            id: Uuid::new_v4(),
            title,
            destinations: vec![Destination { country_code: country_code.to_uppercase(), city }],
            window: TravelWindow::Month { year, month },
            nights,
            travellers: traveller_names
                .into_iter()
                .map(|name| Traveller { id: Uuid::new_v4(), name })
                .collect(),
            purposes: purposes.iter().filter_map(|p| parse_purpose(p)).collect(),
        };
        let id = trip.id;
        let mut doc = TripDocument::new(&trip);
        self.store.save(&mut doc).map_err(core_err)?;
        Ok(id.to_string())
    }

    pub fn load_items(&self, trip_id: String) -> Result<Vec<ItemDto>, SundryError> {
        let id = parse_id(&trip_id)?;
        let doc = self.store.load(id).map_err(core_err)?;
        Ok(doc.items().map_err(core_err)?.into_iter().map(Into::into).collect())
    }

    pub fn set_item_state(
        &self,
        trip_id: String,
        item_id: String,
        state: ItemStateDto,
    ) -> Result<(), SundryError> {
        let tid = parse_id(&trip_id)?;
        let iid = parse_id(&item_id)?;
        let mut doc = self.store.load(tid).map_err(core_err)?;
        doc.set_item_state(iid, state.into()).map_err(core_err)?;
        self.store.save(&mut doc).map_err(core_err)
    }

    pub async fn generate(&self, trip_id: String) -> Result<GenerationOutcomeDto, SundryError> {
        let id = parse_id(&trip_id)?;
        let mut doc = self.store.load(id).map_err(core_err)?;

        let climate = ClimateAdapter(self.climate.clone());
        let llm = LlmAdapter(self.llm.clone());
        let generator = Generator::new(&self.facts, &climate, &llm);

        let outcome = generator.generate_all(&mut doc).await.map_err(core_err)?;
        self.store.save(&mut doc).map_err(core_err)?;

        Ok(GenerationOutcomeDto {
            climate_grounded: outcome.climate_grounded,
            per_category: outcome
                .per_category
                .into_iter()
                .map(|c| CategoryOutcomeDto {
                    category: c.category.label().to_string(),
                    added: c.added as u32,
                    error: c.error,
                })
                .collect(),
        })
    }
}

fn parse_purpose(raw: &str) -> Option<Purpose> {
    match raw {
        "business" => Some(Purpose::Business),
        "leisure" => Some(Purpose::Leisure),
        "hiking" => Some(Purpose::Hiking),
        "beach" => Some(Purpose::Beach),
        "city" => Some(Purpose::City),
        _ => None,
    }
}

/// Referenced so `Category` stays linked; also used by the app to render section order.
#[uniffi::export]
pub fn category_order() -> Vec<String> {
    Category::ALL.iter().map(|c| c.label().to_string()).collect()
}
```

```swift
import Foundation

enum ModelAvailability {
    case available
    case notEnabled
    case downloading
    case ineligible(String)
}

func currentAvailability() -> ModelAvailability {
    switch SystemLanguageModel.default.availability {
    case .available:
        return .available
    case .unavailable(.appleIntelligenceNotEnabled):
        return .notEnabled
    case .unavailable(.modelNotReady):
        return .downloading
    case .unavailable(let other):
        return .ineligible("\(other)")
    }
}

final class FoundationModelsBackend: LlmTransport {
    func generate(prompt: String) async throws -> String {
        guard case .available = currentAvailability() else {
            throw SundryError.Core(message: "the on-device model is unavailable")
        }
        let session = LanguageModelSession()
        let response = try await session.respond(to: prompt, generating: GeneratedListSchema.self)
        let data = try JSONEncoder().encode(response.content)
        guard let json = String(data: data, encoding: .utf8) else {
            throw SundryError.Core(message: "could not encode model response")
        }
        return json
    }
}
```

```swift
// sundry-mac/Sundry/Backends/OpenMeteoClimateProvider.swift
import Foundation

/// Open-Meteo requires no API key and no account.
final class OpenMeteoClimateProvider: ClimateTransport {
    private struct GeocodeResponse: Decodable {
        struct Result: Decodable { let latitude: Double; let longitude: Double }
        let results: [Result]?
    }

    private struct ClimateResponse: Decodable {
        struct Daily: Decodable {
            let temperature_2m_max: [Double?]
            let temperature_2m_min: [Double?]
            let precipitation_sum: [Double?]
            let daylight_duration: [Double?]
        }
        let daily: Daily
    }

    func normals(city: String, countryCode: String, month: UInt32) async -> ClimateNormalsDto? {
        guard let coords = await geocode(city: city, countryCode: countryCode) else { return nil }
        return await normals(at: coords, month: month)
    }

    private func geocode(city: String, countryCode: String) async -> (Double, Double)? {
        var components = URLComponents(string: "https://geocoding-api.open-meteo.com/v1/search")!
        components.queryItems = [
            .init(name: "name", value: city),
            .init(name: "countryCode", value: countryCode),
            .init(name: "count", value: "1"),
        ]
        guard let url = components.url,
              let (data, _) = try? await URLSession.shared.data(from: url),
              let decoded = try? JSONDecoder().decode(GeocodeResponse.self, from: data),
              let first = decoded.results?.first
        else { return nil }
        return (first.latitude, first.longitude)
    }

    /// Uses the most recent complete decade as the climate baseline.
    private func normals(at coords: (Double, Double), month: UInt32) async -> ClimateNormalsDto? {
        let start = String(format: "2014-%02d-01", month)
        let daysInMonth = Calendar(identifier: .gregorian)
            .range(of: .day, in: .month, for: DateComponents(
                calendar: Calendar(identifier: .gregorian), year: 2014, month: Int(month), day: 1
            ).date!)!.count
        let end = String(format: "2023-%02d-%02d", month, daysInMonth)

        var components = URLComponents(string: "https://archive-api.open-meteo.com/v1/archive")!
        components.queryItems = [
            .init(name: "latitude", value: "\(coords.0)"),
            .init(name: "longitude", value: "\(coords.1)"),
            .init(name: "start_date", value: start),
            .init(name: "end_date", value: end),
            .init(name: "daily", value: "temperature_2m_max,temperature_2m_min,precipitation_sum,daylight_duration"),
            .init(name: "timezone", value: "auto"),
        ]

        guard let url = components.url,
              let (data, _) = try? await URLSession.shared.data(from: url),
              let decoded = try? JSONDecoder().decode(ClimateResponse.self, from: data)
        else { return nil }

        func mean(_ values: [Double?]) -> Double {
            let present = values.compactMap { $0 }
            guard !present.isEmpty else { return 0 }
            return present.reduce(0, +) / Double(present.count)
        }

        let daily = decoded.daily
        // precipitation_sum is a daily total; report a monthly total.
        let monthlyPrecipitation = mean(daily.precipitation_sum) * Double(daysInMonth)

        return ClimateNormalsDto(
            avgHighC: mean(daily.temperature_2m_max),
            avgLowC: mean(daily.temperature_2m_min),
            precipitationMm: monthlyPrecipitation,
            daylightHours: mean(daily.daylight_duration) / 3600.0
        )
    }
}
```

The archive endpoint is used rather than a forecast endpoint because a trip may be months away, and ten years of the same calendar month is a better basis for packing than a forecast that doesn't exist yet.

```swift
// sundry-mac/Sundry/ViewModels/TripStore.swift
import Foundation
import Observation

enum GenerationState: Equatable {
    case idle
    case running(completed: Int, total: Int)
    case finished(climateGrounded: Bool, failures: [String])
    case failed(String)
}

@Observable
@MainActor
final class TripStore {
    var trips: [TripSummaryDto] = []
    var items: [ItemDto] = []
    var selectedTripId: String?
    var isCreatingTrip = false
    var generationState: GenerationState = .idle
    var categoryOrder: [String] = categoryOrder()

    private let core: SundryCore

    init() {
        let root = FileManager.default
            .urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
            .appendingPathComponent("Sundry", isDirectory: true)
        try? FileManager.default.createDirectory(at: root, withIntermediateDirectories: true)

        core = SundryCore(
            storageRoot: root.path,
            climate: OpenMeteoClimateProvider(),
            llm: FoundationModelsBackend()
        )
        refresh()
    }

    func refresh() {
        trips = (try? core.listTrips()) ?? []
        if let id = selectedTripId {
            items = (try? core.loadItems(tripId: id)) ?? []
        } else {
            items = []
        }
    }

    func select(_ id: String?) {
        selectedTripId = id
        generationState = .idle
        refresh()
    }

    func createTrip(
        title: String,
        city: String,
        countryCode: String,
        year: Int32,
        month: UInt32,
        nights: UInt32,
        travellers: [String],
        purposes: [String]
    ) {
        guard let id = try? core.createTrip(
            title: title,
            city: city,
            countryCode: countryCode,
            year: year,
            month: month,
            nights: nights,
            travellerNames: travellers,
            purposes: purposes
        ) else { return }
        isCreatingTrip = false
        select(id)
        Task { await generate() }
    }

    func toggle(_ item: ItemDto) {
        guard let tripId = selectedTripId else { return }
        let next: ItemStateDto = item.state == .packed ? .todo : .packed
        try? core.setItemState(tripId: tripId, itemId: item.id, state: next)
        refresh()
    }

    func generate() async {
        guard let tripId = selectedTripId else { return }
        let total = categoryOrder.count
        generationState = .running(completed: 0, total: total)
        do {
            let outcome = try await core.generate(tripId: tripId)
            let failures = outcome.perCategory.compactMap { c in
                c.error.map { "\(c.category): \($0)" }
            }
            generationState = .finished(
                climateGrounded: outcome.climateGrounded,
                failures: failures
            )
        } catch {
            generationState = .failed(error.localizedDescription)
        }
        refresh()
    }
}
```

The v1 core returns progress only when generation completes, so `running` carries a total but does not tick. Per-category progress reporting is a follow-up; keeping the state shape ready for it costs nothing.

```swift
            Text("\(monthName(trip.month)) \(String(trip.year))")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
        .tag(trip.id)
    }

    private func isUpcoming(_ trip: TripSummaryDto) -> Bool {
        let now = Calendar.current.dateComponents([.year, .month], from: .now)
        guard let y = now.year, let m = now.month else { return true }
        return (Int(trip.year), Int(trip.month)) >= (y, m)

    private func chronological(_ a: TripSummaryDto, _ b: TripSummaryDto) -> Bool {
        (a.year, a.month) < (b.year, b.month)
    }

    let names = Calendar.current.monthSymbols
    let index = Int(month) - 1
    return names.indices.contains(index) ? names[index] : "?"
```

```swift
// sundry-mac/Sundry/Views/ChecklistView.swift
import SwiftUI

struct ChecklistView: View {
    @Environment(TripStore.self) private var store
    @Binding var selectedItem: ItemDto?
    @State private var query = ""

    private var visible: [ItemDto] {
        guard !query.isEmpty else { return store.items }
        return store.items.filter { $0.name.localizedCaseInsensitiveContains(query) }
    }

    private var packedCount: Int {
        store.items.filter { $0.state == .packed }.count
    }

    var body: some View {
        List(selection: $selectedItem) {
            if case .finished(let grounded, let failures) = store.generationState {
                if !grounded {
                    banner(
                        "Generated without climate data",
                        detail: "The weather lookup failed, so this list isn't tailored to the season. Regenerate when you're back online.",
                        icon: "cloud.slash"
                    )
                }
                if !failures.isEmpty {
                    banner(
                        "\(failures.count) categories didn't generate",
                        detail: failures.joined(separator: "\n"),
                        icon: "exclamationmark.triangle"
                    )
                }
            }

            ForEach(store.categoryOrder, id: \.self) { category in
                let inCategory = visible.filter { $0.category == category }
                if !inCategory.isEmpty {
                    Section(category) {
                        ForEach(inCategory, id: \.id) { item in
                            row(item).tag(item)
                        }
                    }
                }
            }
        }
        .searchable(text: $query, prompt: "Find an item")
        .navigationTitle(store.trips.first { $0.id == store.selectedTripId }?.title ?? "Trip")
        .toolbar {
            ToolbarItem(placement: .status) {
                if case .running = store.generationState {
                    HStack(spacing: 6) {
                        ProgressView().controlSize(.small)
                        Text("Building your list…").foregroundStyle(.secondary)
                    }
                } else if !store.items.isEmpty {
                    Text("\(packedCount) of \(store.items.count) packed")
                        .monospacedDigit()
                        .foregroundStyle(.secondary)
                }
            }
            ToolbarItem {
                Button {
                    Task { await store.generate() }
                } label: {
                    Label("Regenerate", systemImage: "arrow.clockwise")
                }
                .disabled(isRunning)
            }
        }
        .overlay {
            if store.items.isEmpty, !isRunning {
                ContentUnavailableView(
                    "No list yet",
                    systemImage: "sparkles",
                    description: Text("Generate a packing list for this trip.")
                )
            }
        }
    }

    private var isRunning: Bool {
        if case .running = store.generationState { return true }
        return false
    }

    private func row(_ item: ItemDto) -> some View {
        Toggle(isOn: Binding(
            get: { item.state == .packed },
            set: { _ in store.toggle(item) }
        )) {
            HStack {
                Text(item.name)
                    .strikethrough(item.state == .packed, color: .secondary)
                if item.quantity > 1 {
                    Text("×\(item.quantity)").foregroundStyle(.secondary).monospacedDigit()
                }
                if item.essential {
                    Image(systemName: "exclamationmark.circle.fill")
                        .foregroundStyle(.orange)
                        .help("Essential")
                }
            }
        }
        .toggleStyle(.checkbox)
    }

    private func banner(_ title: String, detail: String, icon: String) -> some View {
        HStack(alignment: .top, spacing: 10) {
            Image(systemName: icon).foregroundStyle(.orange)
            VStack(alignment: .leading, spacing: 2) {
                Text(title).font(.callout.weight(.medium))
                Text(detail).font(.caption).foregroundStyle(.secondary)
            }
        }
        .padding(8)
    }
}
```

## Self-review notes

**Spec coverage.** Every spec section maps to a task: architecture and crate split (2, 11), domain model including three-valued state and reserved `owner` (3), country facts with the data-quality gate (4), climate grounding via Open-Meteo (5, 12), per-category generation (7, 9), non-destructive merge (8), persistence layout (10), the UniFFI callback-interface boundary and accepted schema duplication (11, 12), the interface described in the spec (13, 14), and each documented failure mode (5, 6, 9, 12, 14). Travel documents are handled by the fixed taxonomy plus the Task 7 prompt guard forbidding asserted entry rules.

**Two deliberate v1 simplifications**, both noted inline where they occur: items are stored as JSON strings inside Automerge rather than as field-level CRDT structures, and the `SundryCore.open` document cache is unused so every mutation reloads from disk. Neither changes any public interface, so neither blocks the sync work on the roadmap.

**One spec item intentionally not implemented as written.** The spec describes retrying a failed category once. Task 9 reports failures per category without an automatic retry; the user-facing Regenerate button covers it, and an automatic retry of a nonsense response tends to produce a second nonsense response. If the Task 1 spike shows retries meaningfully help, add it to `Generator::generate_all` — the `CategoryOutcome` shape already accommodates it.
